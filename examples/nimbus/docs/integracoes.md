# Integrações

## WhatsApp
A integração com WhatsApp está disponível nos planos Pro e Business. Ela permite enviar e receber mensagens dentro do CRM e registra o histórico na ficha do cliente.

## E-mail e agenda
O Nimbus CRM integra com Gmail, Outlook e Google Agenda. Os e-mails trocados com um contato aparecem automaticamente na linha do tempo dele.

## Zapier e API
Conecte o Nimbus a mais de mil aplicativos pelo Zapier. A API REST para integrações personalizadas está disponível no plano Business.

## Importação de dados
É possível importar contatos e negócios por planilha Excel ou CSV em todos os planos.
